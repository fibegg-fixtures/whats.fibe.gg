# fibe_feedbacks_list

Lists feedback entries, optionally filtered by Playground, Agent or status.

## Inputs

- `playground_id_or_name` (optional).
- `agent_id_or_name` (optional).
- `status` (optional).

## Notes

- Address open feedback before reporting work as finished.
