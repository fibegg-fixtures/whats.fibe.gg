# Platform API

These endpoints manage Hosts, application definitions, playground lifecycle, and template import workflows. Every operation below includes path/query parameters, request body examples, response summaries, and an interactive Swagger UI tester.

Host operations that launch, inspect, stream, schedule, stop, destroy, or manage services require current funding. Unpaid Hosts return `HOST_NOT_FUNDED` with status `402`; billing reads remain available.
