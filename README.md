# Native FIBE public guide

Source for [whats.fibe.gg](https://whats.fibe.gg), the Native self-hosted FIBE guide
and public product skills. The application is Rust and SQLite with durable native
jobs and a React UI, distributed as one application image. Operators supply their
own installation URL, Hosts and optional integrations.

## Content authority

[content-sources.json](content-sources.json) records the exact API and UI commits
reviewed on November 2, 2026, and the released SDK consumer version. Current product
vocabulary is Host, Spec, Repository, Team, Task, Agent, Library, Audit Logs and
long-running Playground. Owner-scoped quotas and access controls are part of the product.

Source inspection establishes documented behavior and available handlers; it does
not establish passing provider, Host, Agent or browser workflows. Pages describe
operation acceptance separately from remote completion and identify relevant
limits. The private workspace skills are contributor instructions and are never
imported into this public guide.

## Develop and verify

Use the Node version in `.nvmrc` and the committed dependency lockfile:

```sh
npm ci
npm start
npm run sync-skills
npm run build-llm-skills
npm run build
npm run check-candidate
```

`npm run build` fails on broken links. It also generates search, LLM documents and
per-page social cards. The established CSS, component classes, icons and layouts
are retained during this content refresh.

## Refresh committed Native contracts

In the Native workspace, `fibe-api/` sits beside this checkout. Set `FIBE_API_PATH`
when using another location. The importers read committed Git objects at the exact
API revision in `content-sources.json`; they never fetch, switch, build or modify it.

```sh
npm run import-native-contracts
npm run import-seed-skills
npm run sync-skills
npm run build-llm-skills
npm run check-native-contracts
```

Exact source OpenAPI and route-manifest bytes stay under `source-contracts/`, outside
the published static files. The public API projection follows approved product scope
even when source cleanup is incomplete. `static/native/public-contract.json` records
both source and published hashes; the source identity and Compose schema retain
upstream bytes. Public `fibe-tool-*` guides are the Native API's seeded SDK/CLI/MCP
help corpus; they describe consumer tools, not proof that every tool succeeds on
every installation. Runtime prompts are excluded. When advancing a source pin,
review product prose and examples as well as regenerating these mirrors.

## Files and generated content

- `docs/`: user guide, API pages and curated reference pages.
- `skills/`: canonical product and Compose authoring guides.
- `seed-skills/`: public tool guides selected from the pinned Native API.
- `docs/reference/`: references regenerated by `scripts/sync-skills.mjs`, plus
  curated introduction, JSON-schema and behavior-contract pages.
- `src/data/apiReference.js`: partitions the supported Native OpenAPI into three
  reference pages without inventing request or response schemas.
- `static/native/`: supported public contracts and source/projection provenance; `static/schema.json` and
  `static/schemas/fibe-compose.v1.schema.json` are identical Compose schema mirrors.
- `static/llm-skills.txt`: deterministic public skills index; raw Markdown mirrors
  are generated locally under `static/skills/` and `static/seed-skills/`.
- `plugins/`: search-adjacent LLM text and social-card generation.
- `CONTENT-REVIEW.md`: review scope, checks and preserved non-content files.

## Publication

The origin remains `fibegg-fixtures/whats.fibe.gg`. Its canonical branch is `main`.
Pushes to `main` run the existing GitHub Pages workflow and publish the build to
`whats.fibe.gg`; `static/CNAME` retains that domain. No FIBE application deployment,
installation migration or infrastructure change is part of guide publication.
